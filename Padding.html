Padding Example with Different Values

Welcome!

This card has padding of 20px, which keeps the text away from the edges so it looks clean and readable.

/* ❌ Bad — text sticks to the edge */ .box-bad { border: 2px solid red; padding: 0; } /* ✅ Good — comfortable breathing room */ .box-good { border: 2px solid green; padding: 20px; } padding: 20px; /* all 4 sides */ padding: 10px 20px; /* top/bottom=10, left/right=20 */ padding: 10px 20px 30px; /* top=10, left/right=20, bottom=30 */ padding: 10px 20px 30px 40px; /* top, right, bottom, left (clockwise) */ padding-top: 15px; /* individual side */
